# Spotify-Top-50-Tracks-Analysis-SQL-Data-Analysis-Project

## Spotify Top 50 Tracks Analysis (SQL)

Analyzed the Top 50 Spotify Tracks 2020 dataset from Kaggle to find what actually makes a song a hit. Queried energy, danceability, and key across the top tracks of the year to pull out patterns behind their popularity.
